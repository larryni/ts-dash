Tailscale API key

  1. Open the admin console: Settings → Keys.
  2. Under API access tokens, choose Generate access token.
  3. Copy the tskey-api-… value and paste it here. (An auth key won't work.)
The key is checked with Tailscale, then saved on the dashboard's server. It is never shown again or sent back to the page.
